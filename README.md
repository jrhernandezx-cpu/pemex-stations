# Pemex Stations

Static map and table of Pemex stations (Texas and California).

`index.html` is generated by `build.py` from a private tracking sheet; don't edit it by hand.
`data/stations.csv` holds only the public columns used by the page.

```bash
python3 build.py data/stations.csv   # writes index.html
```

Map: Leaflet + OpenStreetMap. Pins are colored by status; Lost stations are hidden by default.
